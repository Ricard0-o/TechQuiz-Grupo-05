# Prompt de execução do TechQuiz

Analise integralmente as instruções do Trabalho Final TechQuiz no Blackboard e desenvolva uma aplicação web simples, didática e fácil de explicar em apresentação. O tema será Fundamentos de Desenvolvimento Front-End.

## Requisitos funcionais

1. Carregar pelo menos 10 perguntas de um arquivo `perguntas.json` usando `fetch`.
2. Solicitar o nome do jogador antes de iniciar.
3. Exibir uma pergunta por vez, com quatro alternativas e apenas uma correta.
4. Informar acerto ou erro com texto e símbolo, sem depender somente de cor.
5. Mostrar uma explicação e o link da fonte após cada resposta.
6. Calcular a pontuação final por acertos.
7. Salvar e exibir um ranking da sessão com `sessionStorage`.
8. Permitir jogar novamente com o mesmo nome ou iniciar com outro jogador.

## Requisitos técnicos

- Usar HTML semântico, CSS externo, JavaScript sem bibliotecas e JSON local.
- Garantir navegação por teclado, foco visível, contraste adequado e regiões `aria-live`.
- Criar layout responsivo de aproximadamente 1280 px até 360 px sem rolagem horizontal.
- Manter o código organizado, comentado apenas onde a intenção não for óbvia e fácil de explicar.
- Utilizar branches por funcionalidade, merges na `main`, mensagens semânticas e tag `cp1-entrega`.
- Documentar integrantes, regras, execução, estrutura e responsabilidades sem atribuir trabalho não realizado.

## Entregáveis

- Repositório GitHub com o projeto e histórico legível.
- Site publicado por HTTPS no GitHub Pages.
- README completo.
- Documento Word separado explicando a arquitetura, cada arquivo, o fluxo do jogo, as funções JavaScript, os testes e o registro de trabalho.
